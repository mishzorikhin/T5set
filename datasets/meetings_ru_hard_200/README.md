# Русские совещания: сложное извлечение по схеме

200 обучающих пар, 50 текстов, 41 самостоятельный сценарий и 9 контрастных продолжений.
Все тексты и ответы сочинены ассистентом на русском. Это новый синтетический набор, а не реальные записи и не независимая человеческая gold-разметка. Он не использует стенограммы ICSI из предыдущего архива.

## Формат

В каждой строке JSONL `input` содержит:

```
<schema>{JSON Schema}</schema>
<text>{русская стенограмма}</text>
```

`output` — строка с сериализованным JSON, соответствующим именно этой схеме. Дополнительные поля `id` и `metadata` не являются входом модели. Файлы `*_pairs.jsonl` содержат только `input` и `output`.

Четыре представления одной встречи:

1. `tasks`: текущие поручения, названные владельцы, сроки, условия, статус и ID подтверждающих реплик.
2. `minutes`: краткий итог, принятые решения и открытые вопросы.
3. `owners`: распределение текущих работ по владельцам, отдельно нераспределённые.
4. `history`: отменённые поручения, непринятые предложения и завершённые работы.

Не смешивайте output разных представлений. Одна встреча намеренно получает разные ответы при разных схемах.

## Что усложнено

Поздний перенос срока, смена человека или команды, сужение объёма, условное обещание, срок запроса вместо срока ответа, пожелание клиента вместо обязательства команды, старая цитата, уже сделанное, снятое поручение, совместные владельцы и отсутствие владельца. В 10 текстах текущих поручений нет. Контрастные варианты могут менять срок, владельца, состояние или набор задач.

80 пар в `long_context.jsonl` используют длинные диалоги с дополнительным контекстом между назначением и его уточнением. Тексты этих встреч доходят до 4 115 символов. Остальные 120 пар короче. Это законченные искусственные встречи; механического обрезания стенограммы нет. `long_context.jsonl` — подмножество `all.jsonl`, повторно добавлять его к полному файлу нельзя. Для отдельного эксперимента используйте поле `metadata.split`, чтобы сохранить разбиение.

## Длина входа

Полный вход со схемой проверен SentencePiece-токенизатором `google/mt5-small`, revision `c83db3e90edd4c0bc69ad9f075c3d19b1ef56c45`, с одним EOS. Длины: 404–1 468 токенов; длинная часть: 948–1 468. Все меньше 2 048. Это измерение для указанного токенизатора, а не гарантия для T5Gemma, ruT5 или другого checkpoint. Схемы тоже входят в бюджет входа.

Перед обучением проверьте своим точным токенизатором:

```
pip install transformers sentencepiece
python scripts/check_lengths.py --tokenizer YOUR_CHECKPOINT --data all.jsonl --max-input 2048 --max-output 512 --report actual_lengths.json
```

Скрипт не обрезает данные и завершится с кодом 1 при превышении лимита. Если ваш шаблон добавляет префиксы/спецтокены, измеряйте итоговую обучающую строку с ними. Обрезать вход, сохраняя прежний ответ, нельзя: доказательство задачи или отмены может оказаться за границей.

## Разбиение и качество

Train: 152 пары / 31 семейство; validation: 24 / 5; test: 24 / 5. Четыре схемы и все контрастные варианты одного сценария всегда в одной части. Тематики и схемы между частями пересекаются: это тест новых текстов, а не строгий zero-shot тест невиданных схем.

Автоматически проверены JSON Schema Draft 2020-12, наличие ID доказательств, явно названных владельцев и сроков, длина входа и отсутствие пересечения семейств между частями. Это структурные проверки; они не доказывают семантическую исчерпывающую правильность. Разметка авторская, без отдельного независимого рецензента. Улучшение вашей модели пока не измерено.

В `sources.json` доступны реплики и исходная авторская разметка. В `quality_report.json` — точные числа и метод измерения. Сценарии, расширенные реплики и сборщик находятся в `scripts/` для проверки и правки; библиотечный tokenizer/веса в архив не включены. Для воспроизведения загрузите указанный `spiece.model` рядом со скриптами, затем выполните `author_sources.py` и `build.py`; сборщик создаст каталог `meetings_ru_hard_200` рядом со скриптами.

Набор стоит оценивать по ошибкам на отложенных семействах, а не по числу строк. Здесь только четыре схемы: он направлен на понимание диалога и смену задачи при смене схемы. Он не покрывает все возможные бизнес-схемы и стенограммы на десятки тысяч токенов.
