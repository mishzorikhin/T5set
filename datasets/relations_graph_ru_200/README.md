# Отношения → графовые структуры

Опубликовано 10 из 200 пар порциями по 10. Основа — 40 самостоятельных русских текстов, каждый получает пять представлений; это не 200 независимых источников.

Формат: `<schema>{JSON Schema}</schema>
<text>{текст}</text>` → строка `output` с JSON. Каждая схема сама задаёт поля, разрешённые типы и направления отношений.

Представления: `graph` — узлы и рёбра; `triples` — типизированные тройки; `outgoing` — исходящие соседства; `incoming` — входящие соседства без обращения предиката; `claims` — подтверждённые, прямо отрицаемые и возможные связи. В узловых представлениях сохраняются изолированные упомянутые сущности. Одинаковые названия разных типов различаются; псевдонимы объединяются только при прямом указании.

Сценарии: роли и принадлежность, документы и версии, назначение задачи, текущая связь после исправления, поставка и платёж как отдельные узлы событий, зависимости сервисов, доступы, иерархия компонентов, контакты, псевдонимы, похожие названия, отрицания и гипотезы. Транзитивные связи и доступы по цепочке не добавляются. Предположение не становится фактом; отсутствие информации не становится отрицанием.

Идентификаторы e1,e2,... локальны одному примеру и назначены по первому упоминанию сущности. Это учебный формат, не устойчивые глобальные ID базы знаний. В реальной системе идентичность между документами требует отдельного сопоставления.

`batch_*.jsonl` — непересекающиеся порции; склеиваются построчно. Передавайте модели только `input`. Split задан по семействам: 32 train, 4 validation, 4 test; все пять представлений одного текста в одной части. Схемы и тематики пересекаются между частями; это не строгий тест невиданных схем.

Данные синтетические, написаны ассистентом; независимой человеческой gold-проверки нет. Проверены JSON Schema Draft 2020-12, допустимые ссылки на узлы, отсутствие дубликатов рёбер и противоречия confirmed/negated, длина входа по указанному mT5. Проверка структуры не доказывает исчерпывающую семантическую правильность. Для точного training checkpoint перепроверьте длины. Улучшение модели не измерено. Тексты короткие и средние; набор про связь сущностей, а не про длинные стенограммы.
